# v2 · 个人主页重做版

与线上现有站点**并存**，路径 `/v2/`，不影响 `/` 与 `/cases/`。

## 结构

```
v2/
├── index.html                主页（定位 · 作品 · 方法 · 关于 · 联系）
├── styles.css                全站唯一样式表（令牌 + 组件 + 响应式）
├── site.js                   语言切换 / 抽屉 / 复制 / 外链状态 / 主题
├── 404.html
└── work/
    ├── financial-bot.html
    ├── court-diary.html
    ├── image-routing.html
    └── media-to-notes.html   （含样例笔记抽屉与 32 张附图）
```

素材直接复用 `../portfolio-assets/`，未复制。

## 与现状的差异

| 项 | 现状 | v2 |
|---|---|---|
| 体积 | `index.html` 1.7 MB（内联 React + three.js + Tailwind CDN） | 全站 112 KB + 素材 |
| 样式 | 五套独立 `<style>` | 一份 `styles.css` |
| 字体 | Google Fonts 远程 | 系统字体栈，零外部请求 |
| 案例结构 | 四页各写各的 | 统一六段：问题 / 判断 / 取舍 / 验证 / 边界 / 重来 |
| 项目分类 | 无 | ● 运行中 / ◆ 可下载 / ○ 概念 |
| 分享元信息 | OG / Twitter / JSON-LD 全空 | 完整，且每页有独立 og:image |
| 移动端 | 无截图可依 | 390 / 768 / 1024 / 1440 已验 |

## 本地预览

```bash
cd ..            # 到仓库根
python3 -m http.server 8801
# 打开 http://127.0.0.1:8801/v2/
```

必须在仓库根起服务，否则 `../portfolio-assets/` 取不到。
