# 小红书

历史经验：浏览器会话可通过用户扫码登录，页面中可能提供单篇视频资源信息；已有环境中有单篇和合集处理脚本。用户在界面登录，不要求提供或展示 Cookie；状态按环境安全保存，不纳入公开文件。

游客也可能拥有看似有效的会话字段，不能以 Cookie 存在或变化判断登录成功；应检查用户有权访问的目标内容是否实际可见。二维码可能过期、页面可能空白，提供重新打开或刷新操作。合集先列举并核对范围，先验证样本文件可解码及完整，再执行用户授权的批量任务。

历史记录中一次匿名探测未完成登录后端到端验证，后续文档记载了登录取流流程；本 Skill 尚未独立验证现时平台行为或全部合集能力。不可将经验视为所有链接均可下载的保证。遇到验证、付费或权限限制时由用户处理，不尝试绕过。
