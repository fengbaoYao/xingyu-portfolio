# 抖音

历史经验：Playwright 可打开分享链接，从页面相关响应获取作品信息和资源，再选择画质下载；可通过用户授权的浏览器会话或独立浏览器使用登录状态。Python 下载器可能仍依赖 Playwright，不要因称作 API 就假设不需要浏览器。

用户分享文本如果没有实际 URL，请其提供可访问链接。长标题需清理并截短。部分汽水音乐分享链接历史上可解析出作品 ID 后转换成对应视频链接，但应验证身份与内容一致。历史经验还包括单视频及合集枚举；曾处理过 35 集合集，合集预览不一定完整。先核对列表、数量和顺序，再按授权批量下载。

这是既有环境的历史记录，并非本 Skill 的现时兼容性承诺。页面请求或登录方式改变时停止盲目重试，报告问题并使用其他授权获取方式。
