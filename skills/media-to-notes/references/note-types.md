# 笔记类型与默认深度

- **逐字稿**：保留原话、顺序和有意义的停顿；标点、分段、时间戳按用户要求或阅读需要添加。将自动识别与人工校对区分；术语修正要有依据并保留不确定性。不要用摘要替代原文。
- **详细整理**：自然重组语言，保留核心观点、论据、重要例子、数字、技术条件、分歧及结论边界；必要时保留原顺序。不要将整段转写堆成引用。
- **重点摘要**：提取主要结论和支撑理由，保留会改变判断的前提与分歧；不以固定压缩比例牺牲准确性。
- **专题整理**：以用户指定问题为范围，保留与问题相关的上下文和反例；标明材料没有回答的问题。
- **会议纪要**：按内容提取议题、决定、行动项、负责人、期限及未决事项；素材没有明确给出负责人或期限时标记未明确，不推断为事实。

课程可侧重概念、推导、公式、代码和示例；访谈或播客保留重要追问和不同意见；新闻区分事件、报道与受访者主张，注意时间和来源。素材类型只是写作依据，不覆盖用户选择。对混合类型使用合适组合；不靠固定段数或字数判断质量。
