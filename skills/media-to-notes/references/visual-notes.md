# 视频截图与图文笔记

结合逐字稿时间戳定位相关片段，查看原视频并理解上下文。图表、公式、代码、操作状态或事件场景可能值得配图；人物静态画面未必有解释价值。时间戳只是候选，画面可能出现得更早或更晚，要实际查看。

优先选文字清楚、图形完整且与当前论述一致的帧；必要时裁掉无关部分，但保留理解所需上下文。对动态图或分步过程，可选择多帧并解释先后。避免重复、模糊、错误时点或用大量定时抽帧冒充精选。按内容选择数量，不设固定上下限。

将截图保存在成品附近的附件目录，使用相对路径和有意义的替代文本；在相关段落解释截图能说明什么，并保留可追溯时间点。核验文件存在、图片可打开、文字可辨、图文匹配。没有视觉查看能力时，只能报告提取了候选帧及未经人工或视觉检查的限制，不称已精选。
