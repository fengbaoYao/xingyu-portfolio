# 转写与模型选择

优先复用用户已有逐字稿或字幕，同时说明来源和质量尚需核验。否则检查本地可用模型及依赖，再结合语言、说话人数、时长、机器资源和准确度选择；不要把模型大小、速度或准确率写成保证。转写与文字整理可分别使用不同模型。

本地方案不适合时说明原因，提供云端选项：说明会上传音视频还是文本、服务商和可能费用，并使用用户明确选择或已授权的服务。避免将隐私内容发给未经授权的服务。不要索取或输出 API 密钥。

保留原始时间段及识别结果，单独生成整理稿；校验时长覆盖、时间单调性、缺失、重复和异常循环。模型产生的标点、说话人标签和专有名词可能出错；依据原音、页面简介和可靠来源核实，不静默编造修正。长任务应能检查状态、记录失败；断点能力只有工具实际支持时才承诺。
